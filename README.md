- 选题：车间设备故障诊断与维修工单闭环

## 1. 项目简介

面向中小制造企业机加工车间的设备运维痛点，基于多智能体协作实现
“报警解析 → 故障定位 → 备件确认 → 工单派发 → 知识沉淀”闭环。

安全约束：本系统仅做只读辅助决策，不接入设备控制系统，不修改 PLC
参数与工艺配置；高危工况强制转人工。

## 2. 环境要求

- Python >= 3.11
- 安装依赖：`pip install -r requirements.txt`

## 3. 配置说明

复制 `.env.example` 为 `.env` 并填写 `LLM_API_KEY`（可选）。

- 不配置：离线规则模式，零成本可演示、可评测；
- 配置后：自动切换为大模型模式。

`.env` 已加入 `.gitignore`，仓库内不出现真实密钥。

## 4. 运行演示

```
streamlit run main.py
```

浏览器打开本地页面，输入设备报警描述即可体验完整多智能体流程。
离线评测回归：`python eval/evaluate.py`

## 5. 仓库结构（对应赛项附件3）

- `README.md` 项目说明
- `requirements.txt` 依赖清单
- `main.py` 演示入口（Streamlit）

- `eval/` 评测脚本
- `docs/` 测试用例
- `demo/` 演示视频录制脚本与视频链接占位

## 6. 功能清单

1. 分诊智能体：识别设备与报警号，判定高危/越界/常规路由
2. 知识检索智能体：关键词精确匹配 + 向量相似度混合检索，条款级引用
3. 故障诊断智能体：按概率排序的原因与现场确认项
4. 备件与工单智能体：库存查询、替代型号、字段完整的工单草稿
5. 审核兜底智能体：高危转人工、越界拦截、引用一致性校验
6. 相关问题推荐：识别成功后推荐可继续追问的问题，点击即可发起追问
7. 拒答兜底：输入未命中任何已知故障知识时如实声明，不作猜测

## 7. 已知限制

1. 知识库与备件数据均为模拟数据，未对接真实 MES/PLC；
2. 离线模式由规则与检索完成推理，不调用大模型；
3. 输出均为建议，须由具备资质的维修人员现场确认后执行。
